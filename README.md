# Engenharia de Dados — Mercado, Competências e Desenvolvimento Profissional

## Sobre o projeto

Este repositório apresenta o trabalho acadêmico desenvolvido para a análise da carreira de **Engenharia de Dados**, abordando o mercado de trabalho, competências técnicas e comportamentais, vagas, planejamento de carreira e desenvolvimento profissional.

## Objetivo

Analisar o cenário atual da Engenharia de Dados e comparar as competências exigidas pelo mercado com o perfil atual dos integrantes do grupo, identificando gaps e estabelecendo planos de desenvolvimento individual.

## Conteúdo

O trabalho apresenta:

- Análise do mercado de Engenharia de Dados;
- Faixas salariais e referências de mercado;
- Vagas reais e requisitos profissionais;
- Hard Skills e Soft Skills;
- Análise individual dos integrantes;
- Análise de GitHub e LinkedIn;
- Planos de carreira;
- Planos de Desenvolvimento Individual (PDI);
- Feedback por pares;
- Identificação de gaps;
- Plano de ação coletivo;
- Referências utilizadas na pesquisa.

## Área profissional escolhida

**Engenharia de Dados**

O grupo possui diferentes níveis de conhecimento e interesses dentro da tecnologia, mas utiliza Engenharia de Dados como área comum para o desenvolvimento do projeto.

## Tecnologias de interesse
